## 1. 使用规则

- 每个独立提示词必须以 [style-guide.md](style-guide.md) 中对应档位的完整风格锚开头。
- 用户未指定档位时使用 5 级。
- 用户已提供画幅、时长、镜头数、帧率、尺寸或语言时，原样继承。
- 用户或上游未提供的规格保持未指定，不自行固定数值。
- 角色定稿和场景资产可以提供构图建议，但不把建议写成全局风格规则。
- 每条提示词只加入与当前任务有关的负面约束。

## 2. 项目级连续性块

批量图、多镜头或完整视频先建立连续性块：

```yaml
continuity_lock:
  character_anchor: "[身份、类型、体型、主色、服装、面部标记]"
  scene_anchor: "[地点、入口、固定物件、行动区、空间方向]"
  material_anchor: "[低保真数字鼠标绘画、平面色块与用户指定材质]"
  light_anchor: "[用户指定的明暗、冷暖与简化光线关系]"
  camera_anchor: "[仅填写用户或上游明确的景别、机位与运动方向]"
  motion_anchor: "[主要动作、方向、接触关系与结束状态]"
  prop_anchor: "[关键道具的数量、位置、用途与状态]"
```

没有明确值的字段省略，不用示例值替代。

## 5. 角色资产模板

角色资产构图只作为可选建议。用户已指定用途、构图、背景或画幅时，删除建议并继承用户要求。

```text
[对应档位的完整风格锚]
生成单个角色“[角色名]”的[全身主形象图/半身表情图/用户指定用途]，只展示该角色，用于角色一致性定稿。[可选构图建议：角色完整入画、主体清楚、背景简洁；不写固定画幅]。[物种/身份/年龄感]，[体型与轮廓]；[面部锚点]；穿[服装与主色]，携带[道具]；状态为[情绪、姿势、手势]。必须保留：[3–6 个短而硬的身份锚点]。保持[用户指定配色]，按当前档位呈现[相关线条、填色、比例或结构缺陷]。[仅继承用户或上游明确的输出规格]。不要[其他角色、复杂场景、设定卡、可读文字、精致风格或擅自改变配色]。
```

身份锚点使用短而硬的描述，例如：

```text
橙色短发、左眼下方小痣、黄色宽松外套、绿色斜挎包、白色运动鞋、双手插兜站姿
```

## 6. 场景资产模板

场景主视图只作为可选建议。用户已指定用途、构图、背景或画幅时，删除建议并继承用户要求。

```text
[对应档位的完整风格锚]
生成一张[时间+地点]的[用户指定场景资产类型；未指定时可建议采用完整展示主要空间结构的主视图]。[用户或上游明确的画幅、景别与机位]。展示[空间结构]：[左/中/右或前/中/后景的固定布局]；[关键道具及数量]；[入口、窗户和行动区]。[用户指定配色与光线]，[情绪]。画面中[是否出现角色]。按当前档位呈现[相关线条、填色、比例或结构缺陷]；保留必要留白，但地面、家具和必要空间结构保持可辨识。[仅继承用户或上游明确的输出规格]。不要[无关人物、可读文字、水印、精致透视或擅自改变配色]。
```

连续场景把不可变化项写入每个独立提示词：

```text
固定：[入口位置、窗户位置、主要物件位置、行动区、主光方向和综合色关系]。
```

## 10. 多镜头与完整视频

- 先锁定角色、场景、道具、配色与用户明确的总时长，再按事件节点切镜。
- 用户指定总时长时，让镜头时长之和等于该值；用户未指定时不自行固定总时长或单镜时长。
- 每个镜头承担一个清楚的动作或剧情功能，不把多个复杂动作挤进同一短镜头。
- 前一镜头的结束姿势、移动方向和道具状态成为后一镜头的起点。
- 用户要求逐镜独立提示词时，每条开头重复完整画面风格锚。
- 用户只要一条完整视频提示词时，只在总提示词开头写一次风格锚，再按事件或用户明确的时间段展开。
- 把写实材质与复杂粒子转换成简笔手绘表现，不劣化动作质量、物理关系或镜头功能。

逐镜结构：

```text
镜头 [编号]
起始状态：[角色、道具、环境、光线]
主体动作：[预备—主动作—结果—停顿或衔接]
环境响应：[场景、道具、特效反馈]
镜头运动：[景别、机位、路径、速度、结束构图]
风格保持：[当前档位的形体、线条、填色与动画规则]
结束状态：[下一镜继承状态]
连续性：[身份、服装、道具、空间、光源、方向和时间]
输出规格：[仅继承用户或上游明确值]
```

```text

```

## 12. 交付前检查

### 图像

- 是否从完整档位锚开始。
- 是否保留主体身份、人数、关键道具、主色和动作含义。
- 是否明确了必须保留和允许改变的部分。
- 是否实施具体重绘，而不是只加风格滤镜。
- 是否只继承用户或上游明确的输出规格。

### 视频

- 是否只使用画面档位，没有动态档位。
- 是否写清起始状态、动作过程、环境响应、镜头运动和结束状态。
- 动作是否具有起点、过程、重点和结束姿势。
- 特效是否采用手绘线条、平面色块和简笔形状，同时保持时序与因果。
- 是否保持人数、身份、服装、配色、道具、场景和空间方向连续。
- 是否避免角色复制、换脸、道具增殖、场景漂移和动作未完成。
- 是否只继承用户或上游明确的画幅、时长、镜头数和帧率。
